# รู้จัก Agents และเลือกงานที่เหมาะสม

ช่วงนี้เป็นการพูดคุยและยกตัวอย่าง ผู้เรียนไม่ต้องเปิด Agent Builder หรือสร้าง agent

## ต่างจากแชตทั่วไปอย่างไร

แชตทั่วไปเหมือนบอกเพื่อนร่วมงานว่าจะให้ช่วยอะไรในครั้งนี้ ส่วน agent ที่กำหนดไว้เหมือนให้เพื่อนมี job description ประจำ: บทบาท ขอบเขตข้อมูล และวิธีตอบที่ใช้ซ้ำได้ ผลยังต้องตรวจโดยคน และการทำงานได้จริงขึ้นกับสิทธิ์และการตั้งค่า

## ตัวอย่างงานที่อาจเหมาะ

- ช่วยทบทวน meeting recap ตามรูปแบบเดิมทุกครั้ง
- ช่วยร่างคำตอบโดยใช้คำแนะนำและข้อมูลที่อนุมัติแล้ว
- ช่วยแยกสิ่งที่ยืนยัน ข้อเสนอ และคำถามที่ยังขาดข้อมูล

## ลองคิดหนึ่งงาน

เลือกงานซ้ำที่พบในวันนี้ แล้วอธิบายสั้น ๆ:

1. ต้องการให้ผู้ช่วยทำอะไร
2. อนุญาตให้ใช้ข้อมูลไหน
3. ต้องให้คนตรวจอะไร และควรหยุดเมื่อใด

หากงานต้องส่งข้อความ อนุมัติ เปลี่ยนระบบ หรือใช้ข้อมูลเพิ่มเติม ต้องประเมินสิทธิ์และการออกแบบก่อน ไม่ถือว่าการเขียนคำสั่งเพียงอย่างเดียวทำให้ agent ทำสิ่งนั้นได้
