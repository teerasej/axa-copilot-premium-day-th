# Management Pitch

Turn evidence into a recommendation. Work on this challenge only; use Level 2 to improve the same output if you finish early.

[← Change challenge](../05-group-challenge) · [Prepare for the showcase →](../07-group-showcase)

> **License:** Use the course's paid Microsoft 365 Copilot access and the Excel/PowerPoint capabilities available in your account. If a Copilot command is unavailable, use standard editing or a prepared backup and identify the route you actually used.

## Get ready

- Open your morning `Asteria_KPI_Dashboard.pptx` and `Asteria_Service_KPI_Reviewed.xlsx`. If needed, use the [presentation template](/files/Asteria_Presentation_Template.pptx) and [reviewed workbook backup](/files/Asteria_Service_KPI_Reviewed_backup.xlsx). Check the backup evidence before using it.
- Use synthetic Asteria data only. Save a group copy; do not overwrite source files.
- Rotate the Operator and Evidence checker. In a group of three, combine Challenger and Presenter. See the [role guide](../05-group-challenge#prepare-your-group-and-files).

## Practice 1: Level 1 — Create a three-slide recommendation

**Primary target:** Communicate one recommendation in three slides using verified evidence.

1. Save a group copy of your morning dashboard. If unavailable, use the presentation template and reviewed workbook. Select one issue only.
2. Ask Copilot for an outline using the synthetic evidence you checked:

   ```text
   Use our selected Asteria evidence to structure a three-slide recommendation: 1) Situation 2) Evidence 3) Proposed action. Focus on one issue, show the supporting data and separate proposals from confirmed decisions. Do not invent owners, due dates or returns. Write in English.
   ```

3. Adapt three existing slides or assemble them from the template. Include one checked chart or table. Do not start a long new deck.
4. Check one value against the workbook and identify what still needs confirmation. Rehearse within the presentation time limit.

### Quick check

- The three slides connect Situation, Evidence and Proposed action.
- Evidence matches its source, and recommendations are not presented as approvals.

**Level 1 output:** Three slides: Situation, Evidence, Proposed action.

Passing these checks completes the required challenge. Start Level 2 only if time remains before the instructor’s checking/rehearsal cue.

## Practice 2: Level 2 — Answer a management objection

**Primary target:** Strengthen the proposed action by addressing one likely management objection with evidence or an explicit information gap.

1. Ask the Challenger to raise one question a manager might ask about your recommendation, such as whether the evidence is sufficient to act.
2. Give Copilot your three-slide text, checked synthetic evidence and that question:

   ```text
   Help us address this management objection using only the supplied Asteria evidence. Suggest a concise response and one improvement to our Proposed action slide. If evidence is missing, state what must be checked before deciding. Do not invent owners, due dates, returns or approvals. Keep the recommendation to three slides. Write in English.
   ```

3. Check the suggested response against the source. If it is unsupported, replace it with a clear statement of the missing evidence and the next check needed.
4. Strengthen the existing Proposed action slide with the checked response or information gap. Keep it readable and rehearse explaining the change without adding a fourth slide.

**Level 2 output:** The same three-slide recommendation with one objection addressed on the Proposed action slide.

### Quick check

- The response is supported by evidence or clearly identifies what is missing.
- The deck stays at three slides and separates the proposed action from an approved decision.
