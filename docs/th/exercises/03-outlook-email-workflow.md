# Exercise 3 Handle one email thread and prepare a checked reply

<ExerciseHeaderImage src="/images/exercise-headers/03-communicate-accountably.png" alt="Read email context and prepare a follow-up message" />

Start by prioritizing recent emails in Copilot Chat, then open one verified thread in Outlook to understand it and prepare a reply. Practices 4–5 are optional: find a specific thread or prepare a handover brief. The separate six additional email practices remain available for further practice.

> **License:** This course requires paid Microsoft 365 Copilot access. Verify email search in Copilot Chat and Copilot in Outlook with the learner account before class. Controls depend on the client and organizational policy.

<span id="เตรียมก่อนเริ่ม" class="legacy-anchor" aria-hidden="true"></span>

## Before you start

- Prepare one approved thread and a short date range.
- Use real work data only within the approved classroom scope. Exclude customer, health, claims, payment, HR and confidential information.
- Turn off screen sharing, keep results private and leave messages unsent. Do not use real-work outputs in the group challenge.
- If data or access is unavailable, use the [Asteria route](#asteria-route) immediately.

## Practice 1 Decide which emails need attention first

<PracticeIllustration id="ex03-prioritize" alt="A person selects a priority envelope from a small group beside a clock." />

**Primary target:** Choose which recent emails to handle first using source evidence.

1. Open a private **Copilot Chat → New chat** with approved work-data access.
2. Replace the dates and send:

   ```text
   Review emails received between [start date] and [end date].
   Suggest up to five that need my attention.

   Show: Email / Action needed / Stated deadline / Priority reason / Source.
   Base priority on stated deadlines and impact. Mark unknowns clearly.
   Respond in English. Do not send messages or change my mailbox.
   ```

3. Open the cited emails, check the reasons and choose your first priority. Open one suitable thread in **Outlook** for Practices 2–3. If no suitable result is available, open your prepared thread or use the [Asteria route](#asteria-route).

### Quick check

- Explain your first priority using source evidence. Treat the shortlist as suggestions, not a complete inbox audit.

## Practice 2 Understand the request and latest status

<PracticeIllustration id="ex03-p2" alt="A reader identifies the requested action and latest message in a thread." />

**Primary target:** Summarize the thread so you know what needs a response.

1. In the selected **Outlook** thread, use `Summarize` or `Summary by Copilot`, depending on your screen.
2. Compare the summary with the source messages. Identify the main request, latest status and unanswered questions.
3. If an available Copilot input is confirmed to use this thread, send the request below. Otherwise check the available summary directly against the source:

   ```text
   Summarize this thread in English in no more than three points: the main request, latest status and unanswered questions. Separate proposals from confirmed agreements. Use To confirm for missing information.
   ```

### Quick check

- The main request and latest status match the source messages.

<span id="practice-3-ร่างและปรับ-reply" class="legacy-anchor" aria-hidden="true"></span>

## Practice 3 Draft and refine a reply

<PracticeIllustration id="ex03-p3" alt="Hands refine an unsent reply beside its source conversation." />

**Primary target:** Prepare a clear reply that preserves existing commitments.

1. Select **Reply** in the same thread. Open `Draft with Copilot` or the drafting control available in your account, then send:

   ```text
   Draft a polite, concise reply in English to this thread. Answer what can be confirmed, identify information still needed and end with a next step. Do not invent approvals, delivery dates or new commitments. Keep it as a draft only.
   ```

2. Read the draft and use the available refinement controls, or edit manually. If a typed refinement is supported, use:

   ```text
   Shorten the draft and put the response needed from the recipient first. Preserve names, dates, numbers and existing agreements. Do not send the message.
   ```

3. Check the recipient, facts and next step against the source. Keep the draft without selecting **Send**. If refinement is unavailable, identify your changes as manual editing rather than successful Copilot coaching.

### Quick check

- The unsent draft answers the main request without adding promises.
- Explain one change that makes the reply clearer.

## Practice 4 Select the relevant thread (optional)

<PracticeIllustration id="ex03-p1" alt="A person selects a relevant email thread with a magnifying glass." />

**Primary target:** Find and open the correct source email for one work topic.

1. Open a private **Copilot Chat → New chat** with approved work-data access. Replace the bracketed details before sending:

   ```text
   Find emails about [prepared topic] between [start date] and [end date]. Show up to three results with their subject, date and source citation. Say clearly if you cannot find them. Respond in English.
   ```

2. Open a citation in **Outlook**. Check its subject and date, then select one thread.
3. If search fails, open the prepared thread directly rather than searching for another topic. Use Asteria if no suitable source is available.

### Quick check

- Open a source matching the topic and date; do not rely only on the search summary.

## Practice 5 Prepare a handover brief from selected emails (optional)

<PracticeIllustration id="ex03-handover" alt="One colleague hands another a briefing sheet beside a group of source envelopes." />

**Primary target:** Add related emails as work content and use them to prepare a checked handover brief.

1. Open a private **Copilot Chat → New chat** with approved work-data access.
2. Select **+ → Add work content**. Find and add two or three emails about one approved topic; check their subjects and dates. If needed, type `/` and use the email references tab. Confirm the intended emails appear as references in your prompt before continuing. If email references are unavailable, use the [Asteria route](#asteria-route).
3. Send the prompt below, then check the brief against the selected emails:

   ```text
   Using only the emails I added, write a concise English handover brief:
   Current situation / Confirmed decisions / Pending actions with stated
   owners and dates / Questions to clarify.

   Include source references. Separate proposals from agreements.
   Use To confirm for missing information. Keep the brief in this chat.
   ```

### Quick check

- The brief accurately identifies the current situation and next actions, with no invented owners, dates or completed actions.

## Asteria route {#asteria-route}

Open **Copilot Chat → New chat**, separate from real work data. Attach `Asteria_Email_Thread.docx` from the practice files, then send:

```text
Use only the attached Asteria_Email_Thread.docx. Respond in English.
Rank the requests that need attention as of 28 September 2026,
using only deadlines and impact stated in the messages. Cite the messages.
Then summarize the main request, latest status and unanswered questions
in no more than three points. Separate proposals from agreements.
Do not claim to have searched a real mailbox.
```

Check the priority and summary against the file. Use the Practice 3 prompts with “attached file” instead of “thread.” For optional Practice 4, identify relevant messages within the file; for Practice 5, replace “emails I added” with “attached file.” Keep replies and briefs in Chat, unsent.

This is file-based practice, not evidence of Outlook summarization, mailbox search or adding email references. If Copilot is unavailable, work manually from the file and identify the manual fallback.
